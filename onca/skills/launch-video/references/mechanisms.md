# Creative mechanisms

Each concept of the five uses a different one. Pick the ones that fit the product's pain.

- **Participation**: the viewer is given a task (remember a short code) and the closure tests it. The code is just hard enough that viewers scroll back to check it, and it appears only in the opening.
- **Deadpan genre parody**: an absurd idea played with a straight face (a funeral for a lost item).
- **Mini-story told only through the product's UI**: a small drama in a few screens.
- **POV pain plus a satisfying payoff**: the annoying task, then it completes in one action.
- **Visual metaphor**: make an invisible software problem physical, then solve it.
- **Misdirection and reveal**: look like something else, then show the product.

## Why open loops work, and how sure we are

- A hook that opens a question and a closure that answers it is the curiosity-gap idea (Loewenstein's information-gap theory) and the Zeigarnik effect. How well the Zeigarnik effect holds in ads is disputed; treat open loops as a craft principle, not a law.
- TikTok's own creative best practices ask for an early hook, the main point shown early, sound on, 9:16, readable text pace and several very different creatives per ad group (https://ads.tiktok.com/help/article/creative-best-practices). Re-read the page before an ad: its figures change.
- The widely quoted "viewers who pass 3 seconds watch 10 seconds" statistic has no primary source: do not use it.
